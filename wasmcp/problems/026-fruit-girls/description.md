## 🎮 Level 3-26 · Three Fruit Girls

```
  Ancient Greek puzzle! 🏛️

  👧👧👧  Three girls each carry the SAME number of apples 🍎.

  They meet N princes. 👑×N

  Together the girls give K apples to EACH prince.
  (Total given away = N × K apples.)

  After the gifts:
     Each girl has EXACTLY K apples left! 😱
  (Same number as one prince received!)
```

**How many apples did each girl carry at the start?**

---

### 📥 Input

```
N    ← number of princes
K    ← apples given to each prince
```

### 📤 Output

```
[initial apples per girl]
```

---

### 🧪 Examples

| N | K | Output |
|---|---|---|
| `9` | `2` | `8` |
| `6` | `1` | `3` |

**Constraint:** $1 \leq N, K \leq 100{,}000$, $(N+3)$ divisible by 3.
