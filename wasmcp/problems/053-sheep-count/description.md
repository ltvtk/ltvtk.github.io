## 🎮 Level 2-053 · Sheep Count

```
  🐑 Little Miu counts sheep...
  ─────────────────────────────
  Sheep 1 ... zzz
  Sheep 2 ... zzz
  Sheep 3 ... zzz
     ...
  Sheep N ... 💤
```

Little Miu counts sheep to fall asleep!
Each sheep gets its own number, counted from 1 all the way to N.
Help Miu count every single sheep!

---

### 📥 Input

```
N    ← number of sheep to count
```

### 📤 Output

```
Sheep 1
Sheep 2
...
Sheep N
```

---

### 🧪 Examples

| Input | Output |
|---|---|
| `3` | `Sheep 1`↵`Sheep 2`↵`Sheep 3` |
| `1` | `Sheep 1` |

**Constraint:** $1 \leq N \leq 100$
