## 🎮 Level 1-4 · The Bakery

```
   🐰 Rabbit walks in...

   🧁 × N cupcakes
   each costs P 🪙

   💰 Total = ?
```

White Rabbit wants $N$ cupcakes. Each costs $P$ coins.

How much does Rabbit pay?

---

### 📥 Input

```
P    ← price per cupcake
N    ← number of cupcakes
```

### 📤 Output

```
P × N
```

---

### 🧪 Examples

| P | N | Total |
|---|---|---|
| `150` | `4` | `600` |
| `7` | `8` | `56` |
| `1` | `1` | `1` |

**Constraint:** $1 \leq P \leq 10^6,\quad 1 \leq N \leq 10^5$
