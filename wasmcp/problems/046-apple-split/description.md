## 🎮 Level 2-046 · Apple Split

```
  🍎🍎🍎🍎🍎🍎🍎🍎🍎🍎  N=10 apples
  ──────────────────────────
  Friend 1  Friend 2  Friend 3   Mom
    🍎🍎🍎    🍎🍎🍎    🍎🍎🍎     🍎
  Each gets 3          Leftover: 1
```

Little Miu has **N** apples and wants to share them equally among **M** friends.
Each friend gets as many whole apples as possible.
How many does each friend get, and how many leftover apples go to Miu's mom?

---

### 📥 Input

```
N    ← number of apples
M    ← number of friends
```

### 📤 Output

```
[apples per friend] [leftover apples]
```

---

### 🧪 Examples

| Input | Output |
|---|---|
| `10`↵`3` | `3 1` |
| `12`↵`4` | `3 0` |

**Constraint:** $1 \leq N, M \leq 1{,}000$
