## 🎮 Level 1-032 · Name Tag

```
  ┌─────────────────────┐
  │ ---                 │
  │ NAME: Le Minh Anh   │
  │ CLASS: 4A1          │
  │ ---                 │
  └─────────────────────┘
        🏷️ Field Trip Tag
```

Robot Bo's class is going on an exciting field trip!
The teacher asks Bo to print official name tags for every student.
Each tag has a special format with dashes as borders — help Bo print them perfectly!

---

### 📥 Input

```
name    ← student's full name (may contain spaces)
class   ← class name (e.g. 4A1)
```

### 📤 Output

```
---
NAME: [name]
CLASS: [class]
---
```

---

### 🧪 Examples

| Input | Output |
|---|---|
| `Le Minh Anh`↵`4A1` | `---`↵`NAME: Le Minh Anh`↵`CLASS: 4A1`↵`---` |
| `Alice`↵`5B` | `---`↵`NAME: Alice`↵`CLASS: 5B`↵`---` |

**Constraint:** Name is 1–50 characters; class is 1–10 characters.
