## 🎮 Level 1-3 · Candy Fusion

```
  🐻 Su        🐭 Bi
  [🍬🍬🍬]  +  [🍬🍬]
      A    +     B
          │
          ▼  ⚡ ZAP! ⚡
          │
     [🍬🍬🍬🍬🍬]
          A + B
```

Su Bear and Bi Mouse fuse their candy jars with a magic wand!

**Find the total.**

---

### 📥 Input

```
A
B
```

### 📤 Output

```
A + B
```

---

### 🧪 Examples

| Input | Output |
|---|---|
| `15` / `27` | `42` |
| `1` / `1` | `2` |
| `1000000` / `1` | `1000001` |

**Constraint:** $1 \leq A, B \leq 1{,}000{,}000$
