## 🎮 Level 1-039 · Square Yard

```
  ┌─────────────────┐
  │                 │ A meters
  │   Playground    │
  │    A × A m²     │
  │                 │
  └─────────────────┘
      A meters
```

Ti's school is building a brand-new square playground!
The principal wants to cover it completely with artificial grass.
Given the side length **A** meters, how many square meters of grass do they need?

---

### 📥 Input

```
A    ← side length of the square (in meters)
```

### 📤 Output

```
[A × A]
```

---

### 🧪 Examples

| Input | Output |
|---|---|
| `10` | `100` |
| `5` | `25` |

**Constraint:** $1 \leq A \leq 1{,}000$
