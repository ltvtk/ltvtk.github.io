## 🎮 Level 2-056 · Times Table

```
  K = 5:
  5 x 1 = 5
  5 x 2 = 10
  5 x 3 = 15
  ...
  5 x 10 = 50
```

Ti wants a program that prints the full multiplication table for any number K from 1 to 9.
Each line shows K times i equals the result, for i from 1 to 10.
Print the complete table!

---

### 📥 Input

```
K    ← the number whose table to print (1 ≤ K ≤ 9)
```

### 📤 Output

```
K x 1 = [K×1]
K x 2 = [K×2]
...
K x 10 = [K×10]
```

---

### 🧪 Examples

| Input | Output |
|---|---|
| `5` | `5 x 1 = 5`↵`5 x 2 = 10`↵`...`↵`5 x 10 = 50` |
| `2` | `2 x 1 = 2`↵`...`↵`2 x 10 = 20` |

**Constraint:** $1 \leq K \leq 9$
