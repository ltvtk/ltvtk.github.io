## 🎮 Level 1-2 · Parrot Rio

```
  You: "2026"
          │
          ▼
       🦜 Rio
          │
          ▼
  Rio: "2026"
```

Rio the parrot repeats **every number** you say — perfectly.

Your mission: read the number → print it back.

---

### 📥 Input

```
N
```

One integer $N$.

### 📤 Output

```
N
```

Same number, nothing else.

---

### 🧪 Examples

| Input | Output |
|---|---|
| `2026` | `2026` |
| `1` | `1` |
| `99999` | `99999` |

**Constraint:** $1 \leq N \leq 100{,}000$
