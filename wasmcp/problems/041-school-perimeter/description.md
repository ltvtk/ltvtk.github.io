## 🎮 Level 1-041 · School Perimeter

```
  ┌──────────────── L ────────────────┐
  │                                   │ W
  │         School Field              │ W
  │                                   │
  └───────────────────────────────────┘
  
  One lap = L + W + L + W = 2×(L+W)
```

The PE teacher wants students to run one complete lap around the rectangular school field.
The field has length **L** meters and width **W** meters.
How far is one full lap around the field?

---

### 📥 Input

```
L    ← length of the field (meters)
W    ← width of the field (meters)
```

### 📤 Output

```
[2 × (L + W)]
```

---

### 🧪 Examples

| Input | Output |
|---|---|
| `50`↵`30` | `160` |
| `100`↵`50` | `300` |

**Constraint:** $0 \leq L, W \leq 1{,}000{,}000$
