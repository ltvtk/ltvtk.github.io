## Theory: Printing Output

In Python, the `print()` function writes text to the screen and automatically adds a newline at the end.

```python
print("Hello Programming World!")
```

**Key facts:**
- String literals use double `"` or single `'` quotes — both work.
- `print()` with no arguments prints a blank line.
- Every program that produces visible output uses `print`.

This is always the very first thing you learn in any programming language!
