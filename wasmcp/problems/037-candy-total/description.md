## 🎮 Level 1-037 · Candy Total

```
  🎀 Ti's bag    🎁 Teo's bag
   [15 candies] + [20 candies]
         ↓ pool together ↓
        [35 candies total]
           for siblings! 🍬
```

Ti and Teo just came home from a birthday party, each carrying a bag of candy.
They want to pool all their candy to share with their younger siblings.
Help them count the grand total!

---

### 📥 Input

```
A    ← Ti's candy count
B    ← Teo's candy count
```

### 📤 Output

```
[A + B]
```

---

### 🧪 Examples

| Input | Output |
|---|---|
| `15`↵`20` | `35` |
| `0`↵`100` | `100` |

**Constraint:** $0 \leq A, B \leq 10^9$
