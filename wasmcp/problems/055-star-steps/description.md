## 🎮 Level 2-055 · Star Steps

```
  N = 5:
  *
  **
  ***
  ****
  *****
  
  Row i has exactly i stars.
```

Robot Bo wants to decorate the screen with a star staircase!
Row 1 has 1 star, row 2 has 2 stars, and so on all the way to row N.
Print the staircase!

---

### 📥 Input

```
N    ← number of rows in the staircase
```

### 📤 Output

```
*
**
***
...
(N rows total)
```

---

### 🧪 Examples

| Input | Output |
|---|---|
| `3` | `*`↵`**`↵`***` |
| `1` | `*` |

**Constraint:** $1 \leq N \leq 20$
