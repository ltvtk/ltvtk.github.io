## 🎮 Level 1-031 · Robot Greeting

```
  ╔══════════════════════════╗
  ║  🤖  ROBOT KINGDOM       ║
  ║                          ║
  ║  Visitor: Alice          ║
  ║  Bo says: Hello Alice    ║
  ╚══════════════════════════╝
```

Robot Bo stands at the gate of Robot Kingdom, greeting every visitor by name.
Bo is very polite — he always says **Hello** followed by the visitor's full name.
Help Bo write a greeting program so no visitor ever feels ignored!

---

### 📥 Input

```
name    ← the visitor's full name (may contain spaces)
```

### 📤 Output

```
Hello [name]
```

---

### 🧪 Examples

| Input | Output |
|---|---|
| `Bin` | `Hello Bin` |
| `Nguyen Thuy Chi` | `Hello Nguyen Thuy Chi` |

**Constraint:** The name is a non-empty string (1–50 characters).
