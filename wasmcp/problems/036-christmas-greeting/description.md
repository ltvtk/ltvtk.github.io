## 🎮 Level 1-036 · Christmas Greeting

```
  December Calendar
  ┌──┬──┬──┬──┬──┬──┬──┐
  │  │  │  │  │  │  │  │
  │ 1│ 2│...│24│25│26│31│
  └──┴──┴──┴──┴──┴──┴──┘
              ↑
           🎅 Dec 25
       "Merry Christmas!"
```

Santa Claus has a special computer at the North Pole.
On **December 25th**, it displays a special message — on any other day, just a plain greeting.
Program Santa's computer!

---

### 📥 Input

```
X    ← the current day of December (1 ≤ X ≤ 31)
```

### 📤 Output

```
Merry Christmas    (if X == 25)
Hi                 (otherwise)
```

---

### 🧪 Examples

| Input | Output |
|---|---|
| `25` | `Merry Christmas` |
| `13` | `Hi` |

**Constraint:** $1 \leq X \leq 31$
